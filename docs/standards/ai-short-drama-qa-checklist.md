# AI 短劇品管檢查清單

- 清單編號：AV-QA-001；版本：1.0；建立日：2026-11-17
- 責任部門：品管；配套：[工作流](../governance/ai-short-drama-production-workflow.md)、[法律](ai-short-drama-legal-checklist.md)、[財務](ai-short-drama-finance-checklist.md)

## 使用方式
每個作品版本及每次送審候選填一份。逐項標通過、不通過、不適用或待補，附版本／檔案／ID、證據位置、檢查人和日期；不適用須說明。硬性項目失敗或證據缺失即阻擋。自動檢查不代替人類內容審查及 CEO 發布核准。

- 專案／季／集／版本：
- 劇本／故事聖經／分鏡版本：
- 輸出檔與雜湊：
- 工具／模型版與 run ID：
- 目標平台／市場：
- 紅果官方規則核對日期／證據：
- QA、法律、財務覆核人：
- 結論：□ 通過 □ 阻擋 □ 待修正

## A. 劇本與連續性
| 檢查項目 | 結果／證據 |
|---|---|
| 企劃方向、題材、受眾、平台、季集數與預算均有核准。 | |
| 劇本各版、季綱、分集、場次 ID 一致；劇情因果、時間線、角色動機正確。 | |
| 每集開場、衝突、轉折、結果、鉤子和下集承接清晰，無誤導性空承諾。 | |
| 角色固定外型、年齡、心理、妝髮服裝、傷勢與聲線跨鏡符合角色卡。 | |
| 場景佈局、時間、天候、光線方向、鏡頭軸線和道具位置／數量／狀態連續。 | |
| 修改紀錄列出受影響場次、鏡頭、配音、字幕及重驗項目。 | |

## B. 分鏡、生成畫面與聲音
| 檢查項目 | 結果／證據 |
|---|---|
| 每鏡 ID、劇本版本、角色／場景／道具引用有效；無漏台詞或關鍵動作。 | |
| 構圖、視線、動作、畫面安全區、時長和轉場符合分鏡。 | |
| 生成畫面無明顯形體錯誤、閃爍、跳接、意外文字／商標／浮水印。 | |
| 單鏡重做有新版本、run ID、原因，並覆核相鄰鏡與剪輯下游。 | |
| 配音、音樂、音效有來源／授權；音畫同步、混音、台詞完整；無未授權仿聲。 | |
| 字幕文字、角色、標點、翻譯、時間碼與畫面同步正確，人工校對完成。 | |
| 成片解析度、比例、幀率、編碼、音量、時長與檔案限制依當期官方設定實測；有測量證據。 | |

## C. 法務、AI 標識與紅果上架
| 檢查項目 | 結果／證據 |
|---|---|
| 劇本、圖像、影片、聲音、字型、角色、肖像、場景、道具及音樂有合法來源／授權證據。 | |
| AI 生成／合成／顯著修改內容有生成紀錄；適用顯式／隱式標識保留，未刪除或篡改。 | |
| 法律清單完成；適用的微短劇分類、許可／備案／節目編號和播前審核有結論。 | |
| 紅果創作者中心當日官方規則、上傳欄位、檔案參數、AI 聲明、權利材料和投訴途徑已核對；媒體摘要未替代原文。 | |
| 虛擬形象確權如適用，依當期規則處理；不將平台記錄當成權利保證。 | |
| 標題、集數、縮圖、簡介、分季順序和最終成片對應同一版本。 | |

## D. 財務與放行
| 檢查項目 | 結果／證據 |
|---|---|
| 預算、素材授權、AI 工具方案符合 CEO 核准；未啟用未核准付費、超額或 API 點數。 | |
| 成本、收入假設、分帳、退款與稅務資料由財務覆核；估算與實際分開。 | |
| 法律、QA、財務各有獨立結論；所有阻擋已解除，CEO 有明確發布核准。 | |
| 最終輸出、字幕、封面、manifest、權利索引、生成紀錄及版本雜湊齊全；無秘密或測試檔。 | |

**放行規則：** 權利、內容安全、AI 標識、平台、費用或輸出規格存在未解問題不得發布。只縮小受影響部分重驗，須有依賴分析證明未影響部分。

## 原創性、肖像權與一致性硬性檢查

逐項填結果、角色／鏡頭版本、證據 ID、檢查人與日期；不通過或缺證據即阻擋。

| 檢查項目 | 結果／證據 |
|---|---|
| 角色外貌、五官、神態、體態、聲音、妝造、服裝與美術均有本作品原創證據，未仿真人或既有 IP。 | |
| 提示詞及輸入未含「像某明星」「神似某演員」「復刻某角色」等仿製指令；未用未授權肖像、插畫、遊戲／動漫角色或 IP。 | |
| 未上傳、參考、生成或保留可辨識真人肖像；真人本人出演／聲音如適用，書面授權及法律覆核完整，且未用於 AI 仿製。 | |
| 每部作品獨立臉模；同劇核心角色五官、神態、體態可區分；無跨劇臉模重用。 | |
| 同劇跨鏡樣貌、妝髮、服裝與美術風格一致；變體有 ID 與適用場次。 | |
| 分段生成及重做後無變臉、五官融合、畸形或僵硬表情；修正後已重驗相鄰鏡。 | |
| 音樂、字體、場景、服裝、道具及美術素材的來源與商用授權完整。 | |
| 原創稿、提示詞版本、工具／模型版、run ID、輸出雜湊、修改、授權索引及最終資產可追溯。 | |
| AI 標示與元資料符合適用規則並保留；紅果虛擬形象確權未被當成免責或放行依據。 | |

**阻擋處理：** 疑似仿真人／IP 或權利不明時，停止相關角色、素材及相依鏡頭入庫與發布，通知法律、QA、CEO；只保留不含可辨識肖像的事件資訊，隔離受影響資產，以乾淨原創來源重做並重驗。已上架者停止後續推廣／發布，由法律評估平台下架、更正或替換並留存回執。
