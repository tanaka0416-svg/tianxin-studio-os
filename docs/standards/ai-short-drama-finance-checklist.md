# AI 短劇財務檢查清單

- 清單編號：AV-FIN-001；版本：1.0；建立日：2026-11-17
- 責任部門：財務；CEO 核准預算與財務承諾
- 配套：[工作流](../governance/ai-short-drama-production-workflow.md)、[法律](ai-short-drama-legal-checklist.md)、[QA](ai-short-drama-qa-checklist.md)、[AI 訂閱政策](../policies/ai-subscription-policy.md)

## 1. 使用原則
每項企劃、每季預算、追加支出、簽約、上架結算及退款填寫一份。AI 可整理核准資料、試算和對帳差異，不得付款、核准預算、申報稅務或代替會計／稅務專業人員。財務 AI 尚未正式指派。金額、付款帳號、合約與稅務資料存限權位置，不放一般 Git、提示詞或未核准雲端。

## 2. 立項與預算
| 項目 | 檢查內容 | 證據／結果 |
|---|---|---|
| 預算模型 | 分列固定、單集變動、一次性、預備金、不含項目；標幣別、期間、稅費、匯率日期。 | |
| 人力／委外 | 編劇、美術、剪輯、配音、法務、QA、翻譯、修改次數、報價及合約責任。 | |
| AI 服務 | 工具、方案、免費額度、限制、商用條款、超額計費、點數、匯出限制、自動續約與取消日；免費試用不等於零成本。 | |
| 訂閱核准 | ChatGPT Plus、Codex Plus 以外的付費方案、API、席位、外掛或點數須 CEO 有效書面核准和費用上限；免費服務關閉超額付款。 | |
| 權利成本 | 劇本、音樂、角色、肖像／聲音、影像、字型、素材授權費和期限納入預算。 | |
| 平台／發行 | 分帳、平台費、宣傳、退款、結算依最新合同或官方後台核對；未核實數字標估算。 | |
| 風險預備 | 延期、退件、鏡頭重做、重新配音、補權利、下架及法務支出有情境上限。 | |
| CEO 核准 | 記預算版本、上限、期間、限制、付款人、追加方式、失效日期；未核准不得簽約、下單或啟用付費功能。 | |

## 3. 成本、收益與對帳
每筆費用記日期、供應商、用途、季／集／資產 ID、科目、核准 ID、預算／實際金額、幣別、收據索引、付款狀態和負責人；每集成本按生成 run／重做分類。每週或 CEO 指定週期核對已付、承諾、應付及剩餘額；超限先暫停非必要支出並請 CEO 決定，AI 不得加額。
收入分類為平台分帳、授權、合作、廣告或其他合法來源；每項附合同／官方規則來源、期間與適用條件。播放、完播、分成、保底、獎勵、稅費、退款及匯率標實際／官方／估算；至少列低／基準／高情境和損益兩平假設，不保證收益。對帳平台報表、合同、應收、扣款、退款及實際入帳。

## 4. 稅務、付款與退款
財務保存收入／支出分類和憑證索引，核對稅務地域、申報期限、代扣及保存要求；不確定時由合格專業人員確認。AI 不得送出申報、付款、改收款帳戶或簽約。付款前核對收款方、合同、交付驗收、金額、幣別、稅費、CEO 核准及期限；變更帳戶須獨立回撥確認。退款記原因、交易識別碼、金額、平台／供應商規則、核准、回執和帳務調整，不留存卡號或銀行秘密於一般文件。

## 5. 例外、驗收
AI 方案可能扣費、平台分帳不明、預算未核准、退款資訊不一致、稅務適用不明或疑似詐騙時阻擋，不可先付款再補核准。財務驗證數字，秘書整理未決選項至一次會議，CEO 最終決定；疑似扣款或資料外洩先安全停用並通知 CEO，保留紀錄。
驗收：全部支出可對到預算版、核准 ID 和證據；無未核准付費／超額／試用轉付費；每集成本可重算且假設與實際分明；分帳、退款、稅務依當期合同／官方資料並有人覆核；付款秘密及個資未流入 Git 或未核准 AI。
依據：[AI 訂閱政策](../policies/ai-subscription-policy.md)、當期供應商／平台合同和適用稅務機關資料。AI 試算是草稿。
