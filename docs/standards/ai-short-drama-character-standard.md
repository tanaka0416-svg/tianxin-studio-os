# AI 短劇角色資產標準

- 標準編號：AV-CHR-001；版本：1.0；建立日：2026-11-17
- 責任部門：影音企劃／美術；法律與品管覆核
- 配套：[工作流](../governance/ai-short-drama-production-workflow.md)、[場景道具](ai-short-drama-scene-standard.md)、[QA](ai-short-drama-qa-checklist.md)

## 1. 目的
讓角色外觀、心理、表演和情境變化一致、可重現、可追溯。適用真人、AI 圖像／影片、動畫及混合製作。角色卡不代表平台確權或素材已獲商用授權。

## 2. 權責
企劃確認人物功能、動機、弧線；美術管理視覺識別、妝髮服裝和參考素材；品管查跨鏡連續性；法律查真人肖像／聲音、IP、商標、素材和生成服務條款。AI 僅提供候選；責任人核准基準，重大權利疑慮交 CEO。免費圖像 AI 為候選，須先確認商用及資料條款。

## 3. 角色卡欄位
每角建立唯一角色 ID，列作品／季、名稱、年齡或範圍、版本、登場集、角色地位；身體比例、姿勢、臉型、髮色髮型、眼睛、膚色描述、非真人仿冒的顯著特徵及聲線；固定識別特徵與禁止變動項；核心目標、需要、恐懼、價值、矛盾、決策方式、語氣、非語言習慣、情緒觸發點、秘密及觀眾已知資訊；初始狀態與季內角色弧線。
另列情境變體：年齡／時期、日夜、工作／居家／正式場合、妝容、髮型、服裝、配件、情緒、傷勢、濕／乾／整潔狀態，以及生效集／場次；標明固定與可變項。記錄配音音色、語速、情緒範圍、發音、聲音來源和授權。
每項參考圖、聲音、素材記錄作者／來源、授權識別碼、用途、期限、地域、生成工具／模型版、提示詞版、時間、操作者、人工修改及輸出雜湊。敏感權利文件只存限權位置，以證據 ID 引用。

## 4. 外型與變體控制
建立已核准的基準圖集（正側面、全身、代表表情、標準光線），只用已放行素材。提示詞分開固定識別與情境變體，不以名人、演員、社群人物或 IP 角色作相似目標。妝髮、服裝、傷勢變化須有劇情依據和生效場次。時代／年齡跳躍保留核心識別，建立變體 ID。出現外型漂移、額外配件／肢體、服裝穿幫、未授權仿真人或權利疑慮時阻擋，不進影片生成。

## 5. 版本與驗收
v001 起遞增；修改記錄人、原因、差異、生效集／場、依賴鏡頭、舊版位置和核准人。驗收：角色 ID 唯一且劇本引用一致；固定特徵、心理、弧線及可變狀態完整；他人能按卡辨識角色；跨鏡年齡、髮妝、服裝、傷勢、情緒連續；素材權利可查；無未授權真人／IP 模仿；AI 標識可追蹤。下游因變更受影響時重驗圖像、影片、配音與字幕。

## 6. 例外
真人授權、角色確權或平台文件不明時，法律查當期官方規則並阻擋。平台確權僅是證據流程之一，不等於權利保證或發布核准。疑似高度相似、身份誤導或未授權仿聲時停止生成，保存必要非敏感證據並通知 CEO。

## 原創性與外型零容忍補充規範

本節優先於一般參考素材流程；證據與處置依[原創性與肖像權標準](ai-short-drama-originality-and-portrait-rights-standard.md)。

1. 角色須從原創文字設定與視覺參數開始。不得用真人、明星、網紅、既有 IP、遊戲／卡通／動漫角色或未授權插畫作為五官、聲音、妝造、服裝、美術風格的參考、輸入、訓練或提示依據；禁止「像某明星」「神似某演員」「復刻某角色」等提示。
2. 不得上傳、參考、生成或在製作資產中保留可辨識真人肖像。未取得書面授權不得使用真人形象或聲音、聲音克隆；真人出演授權亦不允許將本人轉成 AI 角色或作生成參照。
3. 不得跨劇重用人臉模板、臉部 embedding 或可重現臉模。每部作品核心角色須有獨立五官組合、神態習慣和體態輪廓，不得只換髮色、服裝或配件。
4. 同劇外觀、妝髮、服裝及美術風格依核准角色卡保持一致；劇情變化須有變體 ID、生效場次及核准紀錄。
5. 分段生成、重繪及單鏡重做須檢查變臉、五官漂移、畸形及僵硬表情；未修正不得進入鎖版或上架。
6. 音樂、字體、場景、服裝、道具及美術素材須有涵蓋商業使用範圍的授權證據。美術提交原創設計與生成紀錄；QA 查差異及連續性；法律查來源、權利及服務條款。疑似近似、來源不明或證據缺漏即阻擋。
