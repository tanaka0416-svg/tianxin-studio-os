# AI 短劇場景與道具標準

- 標準編號：AV-SCN-001；版本：1.0；建立日：2026-11-17
- 責任部門：影音企劃／美術；品管與法律覆核
- 配套：[工作流](../governance/ai-short-drama-production-workflow.md)、[角色](ai-short-drama-character-standard.md)、[分鏡](ai-short-drama-storyboard-standard.md)

## 1. 目的與責任
建立跨圖像、影片、剪輯可重用的場景／道具基準，確保空間、時間、光線、物件狀態和鏡頭連續性。企劃定劇情用途；美術維護卡片；分鏡／剪輯引用相同 ID；QA 查連續性；法律查真實地點、藝術品、建築、品牌、道具參考圖及第三方權利。AI 只能產生候選。

## 2. 場景卡欄位
每場景使用唯一 ID，列作品／季／集、場次、版本、狀態；內外景、虛構／真實、時代、地點、時段、日期、季節、天候、故事時間；平面佈局、入口出口、窗戶、家具、樓層、角色初始／移動位置、視線與鏡頭軸線；材質、色彩、風格、背景、可見文字／標誌、須排除元素；光源數量／方向、色調、硬柔、陰影、亮度連續基準；日夜／天候／損壞／清潔等變體及生效場次；參考素材來源／授權、工具／模型版、提示詞版、輸出雜湊；前後場景與角色／道具位置狀態。

## 3. 道具清冊
每項道具使用唯一 prop ID，記名稱、劇情功能、尺寸級距、色彩、材質、文字／標誌、持有人、出現集／場／鏡、初始位置、使用方向、數量、破損／損耗、前後狀態、權利來源及安全限制。消耗品記錄逐鏡數量；關鍵劇情道具留參考圖與狀態變化。品牌產品、藝術品、文件畫面及真實標誌非必要時改用原創／虛構設計；必須使用時先由法律核准。

## 4. 生成與連續性
生成指示分開固定空間描述、可變光線／天候、鏡頭視角及當前道具狀態。連續鏡記錄螢幕方向、人物位置、視線、動作方向、道具持有、光源、時間與天候。任何場景卡變更列出依賴分鏡、圖像、影片、聲音及字幕，保留舊版，只重做有影響項目並重驗。刻意跳接需在劇本／分鏡註明原因；工具無法保持一致時標失敗並人工合成或另定方案，不假稱通過。

## 5. 版本、驗收及例外
版本 v001 起遞增；記錄作者、理由、差異、生效場次、依賴鏡頭、權利證據和核准人。驗收場景／道具 ID 有效；佈局、軸線、光線、時間、天候、角色走位、道具數量與狀態符合劇本；變體有故事依據；生成工具、參考來源、授權可追溯；無意外品牌、文字、浮水印或不相關人物。真實私人地點、敏感地點、第三方藝術品／品牌、災害現場或權利不明時阻擋並交法律／CEO；不得覆寫已核准素材。
