# AI 短劇分鏡標準

- 標準編號：AV-STB-001；版本：1.0；建立日：2026-11-17
- 責任部門：影音企劃／美術；品管覆核
- 配套：[工作流](../governance/ai-short-drama-production-workflow.md)、[劇本](ai-short-drama-script-standard.md)、[角色](ai-short-drama-character-standard.md)、[場景道具](ai-short-drama-scene-standard.md)

## 1. 目的與責任
把鎖稿轉成可生成、拍攝、剪輯和驗收的鏡頭表，支援季集、版本、即時修正、單鏡重做和依賴追蹤。企劃負責敘事與鏡頭目的，美術負責構圖參考，QA 核連續性與規格，法律查素材權利。AI 提供候選，不作核准。

## 2. 每鏡必備欄位
唯一 shot ID（含專案／季／集／場／鏡）、劇本與分鏡版、建立／修改人、狀態；鏡頭目的、資訊與情緒變化、伏筆／鉤子關係；景別、視角、高度、構圖、角色站位、視線、運動方向、鏡頭移動、焦點、畫面安全區、時長和轉場；角色／變體 ID、表情、動作、妝髮服裝、傷勢；場景／道具 ID、光線、時間、天候、物件狀態；台詞／字幕 ID、配音、音樂、音效；生成描述、禁止條件、參考素材來源／權利、工具／模型版、提示詞版、run ID、生成日期、輸出檔／雜湊、人工修改及 QA 結論；前後鏡連續條件、依賴鏡頭與重做原因。

## 3. 生成與修改流程
狀態：草稿、待覆核、鎖定、生成中、待 QA、通過、阻擋、已取代。鎖定前核對劇本版、所有資產 ID 和權利狀態。鎖定後改劇情、演出、外觀、道具、光線、鏡位或字幕時，建立變更單，列理由、差異、核准人、成本及受影響鏡頭。單鏡重做建立新版本／run ID，保留舊通過版，記失敗原因和輸入。依位置、視線、動作、光線或剪輯而依賴的相鄰鏡也需覆核。實際生成偏離核准分鏡須修正或更新分鏡再核准，不得悄悄更改基準。

## 4. 內容與安全
鏡頭須支援因果、角色表演、場面調度及單集結尾鉤子。提示詞不得要求未授權仿真人、品牌角色、現有影視畫面或在世藝術家；不得帶入未核准敏感原文。生成失敗記錯誤類別，不記秘密或敏感內容。每次生成保留顯／隱式 AI 標識資訊，不移除或偽造。

## 5. 驗收與例外
每場次由鏡頭覆蓋；ID 和引用有效；構圖、方向、動作、角色／場景／道具、光線及前後鏡一致；鉤子承接劇本；單鏡重做有新 run 並已重驗依賴項；素材來源／授權、生成紀錄、標識完整。解析度、畫幅、幀率、編碼、音量、時長和檔案大小依每次官方／交付設定檔核對，不在此固定。缺劇本版、資產、權利或資料傳送核准時阻擋。急件仍須 QA、法律按影響覆核與 CEO 發布核准。
