# AI 短劇法律檢查清單

- 清單編號：AV-LEGAL-001；版本：1.0；建立日：2026-11-17
- 責任部門：法律；必要時交合格律師或主管機關
- 配套：[工作流](../governance/ai-short-drama-production-workflow.md)、[QA](ai-short-drama-qa-checklist.md)、[財務](ai-short-drama-finance-checklist.md)

## 1. 用途與紀錄
立項、鎖稿、素材定稿、送審和上架前逐版檢查權利、內容與平台規則。這是內部初篩，非法律意見、不保證無侵權或平台核准。逐項標通過／不通過／不適用／待補；不適用需理由，證據缺失或不確定一律阻擋。
作品／季／集／版：；地域／平台／發布方式：；法規版本與核對日：；平台官方頁面／版本／核對日：；法律覆核人：；權利證據受控位置：；結論：□通過 □阻擋 □待補。

## 2. 權利檢查
| 類別 | 必查事項 | 結果／證據 |
|---|---|---|
| 劇本／改編 | 原創草稿、委託／僱傭權利；小說、漫畫、遊戲、新聞、真實事件、既有作品、角色、台詞、橋段引用的改編範圍、期限、地域、媒體、署名與再授權。來源不明即阻擋。 | |
| 肖像／角色 | 真人姓名、肖像、表演、數位替身、換臉、聲音及可識別特徵有書面授權；列用途、地域、期限、平台、宣傳、剪輯及 AI 生成範圍。AI 虛擬角色保存原創過程或完整上游授權鏈。 | |
| 音樂／聲音 | 配樂、歌曲、歌詞、錄音、音效、配音、聲線模型及表演權逐項核對；禁止未授權仿聲、抽取音軌或把個人播放授權當商用。 | |
| 圖像／影片／場景 | 參考圖、照片、片段、背景、素材庫、字型、地圖、建築、藝術品、文件畫面有來源、授權版本、期限、地域、署名與商用範圍；可下載不等於可商用。 | |
| 商標／品牌 | 劇名、人物名、產品、包裝、標誌、招牌和宣傳文案核查商標、混淆及背書風險；AI 生成的品牌形象也要審查。 | |
| AI 服務 | 留存工具／模型版、條款日期、輸入輸出權利、商業使用、再授權、訓練、資料保留與公開展示條款。免費方案同查；不允許或不明即停用。 | |
| 委外 | 合約明列交付、著作權／授權、肖像聲音、AI 使用、保密、再委託、修改、付款與終止處理。 | |

## 3. 內容、隱私與資料
劇名、劇本、台詞、字幕、影像、配音、封面及宣傳整體檢查誹謗、隱私、個資、歧視仇恨、暴力、未成年人安全、性內容、犯罪教唆及適用禁限內容。真實人物、未成年人、受害者或醫療／金融／司法情境有風險時阻擋並尋求專業意見。研究事實標來源日期，不冒充官方或真實事件。
F002-A 只處理任務標題／描述文字，不會掃描短劇文件及多媒體。敏感內容先於本機最小化／遮蔽；未取得 CEO 對服務商、資料類別、用途、保存和傳輸的明確核准，不得把個資、機密、客戶資料、未公開劇本、權利證件或可識別真人資料送雲端。訂閱核准不等於資料傳輸核准。秘密／完整合約存限權位置，只於清單引用證據 ID。

## 4. AI 標識、法規與紅果
逐項列 AI 生成／合成／顯著修改的文字、圖像、音訊、影片、虛擬場景；留工具、版本、時間、輸入素材 ID、輸出雜湊、人工修改及標識處理。依適用《人工智能生成合成內容標識辦法》、配套標準、工具條款和平台規則，確認顯式提示、元資料隱式標識、上傳聲明及二次加工保留；禁止移除、遮蔽、偽造標識。
每次送審前依作品類型、地域、播出方式核對微短劇分類／許可／批准、備案、節目編號與播前審核適用性，法律責任人簽結論。登入紅果短劇創作者中心核對當期內容規範、權利證明、AI 聲明、虛擬形象提報、上傳欄位、審核、投訴和申訴；記頁名、URL、版本／發布日期、核對日、受控證據與核對人。新聞轉載只作線索；平台確權是權屬資料留存輔助，不保證沒有侵權，也不是發布許可。

## 5. 阻擋、決策與驗收
權利鏈斷裂、商業用途未授權、疑似模仿真人／IP、標識被破壞、適用法規不明、平台規則未核對或敏感傳送未批准，均阻擋。AI 不可放行例外；法律整理事實、來源、選項與風險，秘書併入一次會議，CEO 作公司決定。需要專業判斷時先找合格律師；公司核准不替代法定許可、第三方授權或平台審查。
驗收：每項素材有權利證據；角色／劇本／聲音授權鏈完整；法規分類有結論；AI 標識與上傳聲明有證據；紅果當期原文已核對；阻擋為零、簽核及 CEO 發布核准可追溯。

## 原創性、肖像權、聲音權與 IP 零容忍審查

逐作品、角色、聲音素材及上架版本檢查；記錄結果、證據 ID、法律覆核人及日期。任一項不通過或缺資料即為上架阻擋項。

| 審查項目 | 結果／證據 |
|---|---|
| 角色外貌、五官、神態、體態、聲音、妝造、服裝及美術原創；未模仿或近似真人、名人、網紅、既有 IP、遊戲／卡通／動漫角色。 | |
| 未上傳、參考、生成或保留可辨識真人肖像；無「像某明星」「神似某演員」「復刻某角色」提示。 | |
| 未以未授權真人寫真、明星肖像、插畫、遊戲／動漫角色或 IP 作訓練／生成／參考輸入。 | |
| 真人出演或使用真人聲音前已有書面授權及法律覆核，授權明列用途、平台、地域、期間、商用及剪輯；不推定可 AI 仿製。 | |
| 無未授權仿聲或聲音克隆；音樂、字體、場景、服裝、道具及美術授權覆蓋預定商用與發布範圍。 | |
| 未跨劇重用臉模；核心角色外觀可區分；原創設計、提示詞、生成紀錄、修改、授權索引與最終資產可追溯。 | |
| AI 標示／元資料符合適用規則；紅果虛擬形象確權只作權屬留存輔助。 | |

法律核對原創草稿、提示詞版本、工具／模型版、run ID、輸出雜湊、素材授權與 QA 簽核；權利文件限權保存，以證據 ID 引用。疑似近似、侵權或權利鏈不完整時立即標為阻擋，停用生成、剪輯及發布，通知 CEO／QA。已上架者停止後續推廣與發布，由法律透過平台正式管道評估下架、限制、替換或更正；記錄資產 ID、時間、平台回覆與處置，不在一般證據副本留存可辨識肖像。替換版本須重新通過法律、QA、AI 標示及 CEO 放行。
