- 清單編號：LINE-QA-001
- 版本：1.0
- 建立日：2026-11-15
- 責任部門：品管
- 適用範圍：LINE 靜態貼圖生成、批次生成、格式整理及送審封裝

## 使用方式

每一作品／批次版本各填一份。全部輸出檔逐檔檢查；每項標記通過、不通過或不適用，附檔名、檢查結果與證據位置。不適用須說明理由；任何硬性規格失敗即整批阻擋。官方尺寸／格式可能更新，送審前必須重查官方 [繁體中文靜態貼圖製作準則](https://creator.line.me/zh-hant/guideline/sticker/)及[貼圖審核準則](https://creator.line.me/zh-hant/review_guideline/)；本清單不取代平台上傳介面的驗證。

| 檔案排序按 manifest 與預定上架順序一致，不依檔案系統偶然排序；作品代碼、批次版本與輸出目錄正確。 | □ 通過 □ 不通過 □ 不適用 | |

## B. 尺寸、檔案格式與大小

| 檢查項目 | 結果 | 證據／檔名／缺失 |
|---|---|---|
| 主圖實際像素尺寸恰為 240 × 240；數量 1；檔案大小不超過 1 MB。 | □ 通過 □ 不通過 □ 不適用 | |
| 聊天室標籤圖實際像素尺寸恰為 96 × 74；數量 1；檔案大小不超過 1 MB。 | □ 通過 □ 不通過 □ 不適用 | |
| 每張貼圖圖片寬不超過 370 px、高不超過 320 px；寬與高皆為偶數；每張大小不超過 1 MB。 | □ 通過 □ 不通過 □ 不適用 | |
| 所有輸出經解碼確認為有效 PNG，而非僅副檔名為 `.png`；檔案均可開啟，無損壞或截斷。 | □ 通過 □ 不通過 □ 不適用 | |
| 貼圖圖片解析度至少 72 dpi、色彩模式為 RGB；資料缺失或工具無法確認時已阻擋或取得明確覆核。 | □ 通過 □ 不通過 □ 不適用 | |
| 若使用單一 ZIP，ZIP 實際大小小於 60 MB；剛好 60 MB 或以上判定不通過。 | □ 通過 □ 不通過 □ 不適用 | |
| 主圖、標籤圖與整組貼圖在比例、裁切及可讀性上正常；沒有變形、重要內容被裁掉或因轉檔造成明顯失真。 | □ 通過 □ 不通過 □ 不適用 | |

## C. 透明度與影像品質

| 檢查項目 | 結果 | 證據／檔名／缺失 |
|---|---|---|
| 各圖檔包含有效 alpha 透明資訊；透明背景為真透明，而非白底、棋盤圖或以背景色模擬。 | □ 通過 □ 不通過 □ 不適用 | |
| 批次轉檔、縮放、去背或整理後仍保留應有的透明度；抽查與自動結果不符時逐檔檢查。 | □ 通過 □ 不通過 □ 不適用 | |
| 貼圖圖案裁切後四周約有 10 px 留白且視覺平衡；品管已目視檢查全套，沒有角色／文字貼邊或被裁切。 | □ 通過 □ 不通過 □ 不適用 | |
| 圖像清晰、縮小後仍容易辨識、對比適當；沒有大量過淡、全套單調、數字羅列、僅文字／僅商標等風險。 | □ 通過 □ 不通過 □ 不適用 | |
| 同一批內無意外重複圖、錯圖、版本不一致、可見草稿標記、隱藏測試圖層或非預期簽名。 | □ 通過 □ 不通過 □ 不適用 | |
