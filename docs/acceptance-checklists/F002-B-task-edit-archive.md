# F002-B CEO 手動驗收清單

> 本清單供實作完成後使用。自動測試、合成資料測試或畫面截圖不能代替 CEO 本機手動確認。

## 任務編輯

- [ ] 可由每筆任務進入編輯。
- [ ] 標題、描述、部門、主要負責 AI、優先級、截止日預填正確且可修改。
- [ ] 取消編輯不送出更新，重新載入後資料不變。
- [ ] 儲存後清單更新；重新載入後新值仍保留。
- [ ] 驗證錯誤及網路錯誤有明確提示；草稿保留，沒有誤報成功。

## 更新文字的脫敏

- [ ] 更新標題／描述中的已識別敏感文字會自動遮蔽。
- [ ] 無法可信分類的候選會攔截更新，任務內容保持原值。
- [ ] 遮蔽選項可重新送出並成功更新。
- [ ] 保留原文必須另行確認；事件可追蹤且不含原文。
- [ ] 非敏感文字不被誤改。

## 軟刪除／封存

- [ ] 封存前的確認可取消；取消後不呼叫封存 API，任務仍存在。
- [ ] 確認後任務從一般清單消失；重新載入仍不出現。
- [ ] 在不同篩選與排序下，已封存任務都不出現。
- [ ] 已封存任務不能再透過狀態選單/API 更新狀態。
- [ ] 任務資料未被硬刪除；本階段沒有復原 UI、封存搜尋或封存標記。

## 回歸與畫面

- [ ] 建立任務與 F002-A 脫敏流程正常。
- [ ] 六種既有狀態正常；篩選、排序及長描述展開／收合正常。
- [ ] 桌機與手機操作可用，沒有載入、版本、無障礙操作或畫面錯誤。

## 核准與證據

- [ ] 記錄 CEO 驗收日期、結果、問題與修正需求。
- [ ] 若需正式 migration，確認另一筆 CEO 核准及當下正式資料庫備份已完成；未核准不得執行。
