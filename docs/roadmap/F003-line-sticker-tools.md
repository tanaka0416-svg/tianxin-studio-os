# F003 LINE 貼圖工具開發藍圖

- 藍圖編號：F003
- 版本：1.0
- 建立日：2026-11-15
- 負責單位：開發部門
- 產品範圍：LINE 貼圖生成、靜態貼圖批次生成、格式整理與送審前檢查
- 配套文件：[LINE 貼圖合規政策](../policies/line-sticker-compliance-policy.md)、[LINE 貼圖技術規格](../standards/line-sticker-technical-spec.md)、[法律檢查清單](../standards/line-sticker-legal-checklist.md)、[品管檢查清單](../standards/line-sticker-qa-checklist.md)、[財務檢查清單](../standards/line-sticker-finance-checklist.md)
- 官方來源核對日：2026-11-15（Asia/Taipei）

## 1. 目標

建立一套本機可控、可重現、可追蹤的 LINE 靜態貼圖工作流程，協助將經授權的創作需求轉為貼圖候選圖，按所選張數批次整理，產生符合 LINE 官方當期技術格式的交付包與檢查報告。

完成後應達到：

- 從同一作品需求可建立單張候選素材與完整靜態貼圖組，明確保留素材來源、人工修改與批次版本。
- 批次工具能確定輸出順序，逐檔驗證官方規格，並指出檔案與失敗原因。
- 格式整理不覆寫原始素材；輸出清單與檔案雜湊可對應，交付包可重現。
- 工具結果與法律、品管、財務審查各自獨立；自動檢查通過不代表作品可送審或發布。

## 2. 範圍與邊界

### 2.1 本藍圖涵蓋

- LINE 靜態貼圖生成與人工挑選／修訂流程。
- 靜態貼圖批次生成：依選定的合規張數產生、整理及排序貼圖圖檔。
- 格式整理工具：尺寸與色彩檢查、透明背景檢查、重新命名、排序、metadata／manifest、ZIP 封裝及逐檔錯誤報告。
- 貼圖上架文字欄位的基本格式檢查，但不代替人工校稿與法律審查。
- 送審前的流程狀態、權責簽核、證據位置與版本追蹤。

### 2.2 明確不在本階段範圍

- 動態貼圖、表情貼、主題、音訊、影片、OCR 或其他 LINE 商品類型。
- 自動登入、瀏覽器控制、上傳、送審、定價或發布至 LINE Creators Market。
- 自動判定著作權、商標、肖像權、法律合規、作品原創性或平台審核結果。
- 自動下架、申訴、帳務／稅務申報、付款或退款執行。
- 未核准的付費 AI、API、雲端模型、外部服務或新依賴。生成能力先以本機或依公司《AI 訂閱政策》已核准且符合零未核准費用基準的服務為限；其他服務須另行核准。
- 未經另行核准的資料庫 schema、migration、正式資料寫入或正式素材處理。

## 3. 依據與規格基線

以 LINE Creators Market 官方繁體中文網站現行適用規範為準：

- [靜態貼圖製作準則](https://creator.line.me/zh-hant/guideline/sticker/)：素材數量、尺寸、格式、透明度、色彩、解析度、文字欄位等。
- [貼圖審核準則](https://creator.line.me/zh-hant/review_guideline/)：圖像、文字、道德、商業用途、個資與權利風險。
- [服務條款](https://creator.line.me/zh-hant/terms/)：創作者責任、內容使用、審核、收益與相關條款。
- [使用方法](https://creator.line.me/zh-hant/howto/)：創作者登錄、提交、審核、上架及收款流程。

本次查核的靜態貼圖技術基線如下，僅為 2026-11-15 核對快照；實作前及每次送審前都必須重新確認官方頁面：

| 資產 | 官方快照 |
|---|---|
| 主圖 | 1 張，240 × 240 px，1 MB 以下 |
| 貼圖圖片 | 8、16、24、32 或 40 張；每張最大 370 × 320 px、1 MB 以下；寬高為偶數 |
| 聊天室標籤圖 | 1 張，96 × 74 px，1 MB 以下 |
| 圖檔／影像 | PNG、透明背景、RGB、72 dpi 以上；單一 ZIP 小於 60 MB |
| 文字欄位 | 貼圖名稱 40 字、創意人名稱 50 字、說明 160 字、版權標記 50 字；繁中頁標示全形文字以 2 字計、系統不支援表情符號，版權標記限英文或數字 |
| 留白／內容 | 官方建議／要求貼圖圖案周圍約 10 px 留白；需符合當期貼圖審核準則 |

官方頁未規定本機檔名；工具可使用公司內部命名規則，但必須與 LINE 上傳介面要求分開標示，並提供可核對的映射。

法律部門負責判定適用語言、地區與更新影響；開發部門負責將核准規格實作為可測設定。不得將本表永久寫死而不保留版本。

## 4. 產品功能藍圖

### 4.1 作品與批次管理

- 建立作品代碼、作品版本、目標市場、張數規格、負責人及合規狀態。
- 每次生成與格式處理建立唯一 run ID，記錄工具版本、規格版本、時間、輸入來源識別、輸出清單與檢查結果。
- 保留來源素材與輸出版本的關聯；原始素材唯讀，不在整理流程中覆寫。
- 匯出批次 manifest，列出檔名、類型、順序、byte 大小、實際像素尺寸、格式、色彩模式、透明度、DPI、SHA-256 及工具／規格版本。

### 4.2 貼圖生成與人工修訂

- 依使用者提供且有權使用的創作描述產生靜態候選圖；如使用 AI，記錄核准服務／模型、版本、來源識別及人工修訂紀錄。
- 提供逐張預覽、選用、退回、重生及人工修訂記錄；內容變更後產生新版本，不靜默替換已簽核檔案。
- 不直接以未授權角色、商標、真人肖像、既有貼圖或外部素材作為複製來源。
- 生成輸出是候選素材，不自行判斷原創性、商用權利、違法性或 LINE 可接受性。

### 4.3 靜態貼圖批次生成

- 支援官方允許張數 8／16／24／32／40 張；建立全套張數清單與固定順序。
- 批次缺圖、超量、重複檔或出現未核准素材時整批失敗，不產生可誤認為完成的提交包。
- 支援建立主圖、標籤圖與貼圖圖片之間的對應；人工確認各圖與整套主題一致。
- 批次輸出可重跑且可比較；每次重跑都以新批次版本輸出並更新 manifest。

### 4.4 格式整理與驗證

- 檢查真實 PNG 格式、尺寸、張數、檔案大小、偶數尺寸、RGB、透明 alpha、DPI、文字欄位及 ZIP 大小。
- 依公司內部慣例整理 `main.png`、`tab.png`、`sticker_01.png` 等檔名與上架順序；如官方上傳介面要求其他命名，產生映射表，不宣稱內部格式為 LINE 規定。
- 需要縮放或轉檔時不得變形、丟失透明度、移除必要標示或覆寫原始素材；無法保真時失敗並交人工處理。
- 自動檢查失敗時顯示具體檔名、失敗規則、實測值、預期值及建議下一步；不可只回報籠統「不合格」。
- 提供「技術檢查通過」狀態，但不得使用「法律已通過」「LINE 已核准」等容易混淆的標籤。

### 4.5 送審前合規閘門

- 連結法律、品管與財務檢查清單及簽核證據位置。
- 未完成必需法律／品管檢查、存在阻擋缺失、工具規格版本過期或財務核准未完成時，狀態不可切換為「可送審」。
- 不自動代替部門判斷；由權責部門簽核並記錄時間、版本和結論。
- 不直接提交至 LINE；使用者在官方介面完成送審與上架，工具僅整理候選交付包和證據。

## 7. 驗收標準

### 7.1 自動驗收

- 貼圖張數只接受 8、16、24、32、40；主圖和標籤圖各 1 張。
- 主圖 240 × 240、標籤圖 96 × 74、貼圖不超過 370 × 320；不符合時回報實際值並阻擋。
- 驗證 PNG 內容格式、單檔上限 1 MB、ZIP 小於 60 MB、貼圖圖像寬高為偶數、RGB、alpha 透明及 72 dpi 以上。
- 驗證文字上限、全形計數與官方平台對 emoji 的限制；平台規格變更時有對應設定版本及測試。
- 驗證檔名、順序、批次 ID、manifest、hash、來源／輸出關聯與工具版本一致；修改輸出後舊 manifest 失效。
- 驗證任何缺檔、重複、錯格式、過大、無透明、資料不完整或工具錯誤均 fail closed，不標示可送審。
- 驗證原始素材不被改寫，生成／轉檔輸出有版本隔離，錯誤紀錄不洩漏密碼、金鑰或不必要個資。
- 自動化測試使用合成或已授權素材；法律風險、可辨識性、留白與內容一致性由人工檢查，不以自動測試通過代替。

### 7.2 人工驗收

- 開發確認批次重跑、失敗訊息、來源追溯、版本保存及輸出包行為符合需求。
- 法律確認權利與素材證據流程、AI 使用條件、官方規範版本及內容阻擋可實際執行。
- 品管逐張目視核對全部圖像、透明背景、可讀性、留白、主圖／標籤圖代表性、上架順序與預覽。
- 財務核對服務／生成成本、支出核准、當期定價與收益條款、稅務／付款／退款處理證據；未經核准不產生付費使用。
- CEO 確認整體流程可理解、無載入／版本錯誤、所有阻擋可追蹤，且未將技術檢查誤認為 LINE 審核通過。

### 7.3 放行判定

M4 只在所有自動驗收通過、四部門必要簽核完成、CEO 手動驗收通過、重大缺失結案後，才可提交正式交付候選版本。任何實作提交、合併、推送、正式資料處理或付費服務啟用，仍依當時另行核准範圍執行。

## 8. 主要風險與控制

| 風險 | 控制與停止條件 |
|---|---|
| LINE 官方格式或審查政策變更 | 法律定期追蹤並通知；開發版本化規格與測試；規格未確認時停止生成最終包／送審。 |
| AI 生成內容與第三方作品過度相似或權利不清 | 保存輸入／來源／模型紀錄；逐張人工檢查；法律未確認前阻擋使用；不允許把 AI 輸出視為自動擁有完整權利。 |
| 批次整理誤覆寫原始素材或順序錯誤 | 原始素材唯讀、輸出分版、manifest／hash、全檔清單與目視核對；發生不一致即整批失敗。 |
| 自動檢查誤報通過 | 技術檢查與法律／內容／財務簽核分離；每批逐檔驗收；人工項目明確顯示待檢而非通過。 |
| 未核准的雲端或付費 AI 成本／資料傳送 | 預設本機或已核准免費方案；任何付費、API 或雲端資料處理先依公司 AI 訂閱政策取得書面核准；禁止在未核准時傳送素材。 |
| 財務收益被誤當保證、退款或扣稅處理錯誤 | 僅以當期條款、官方帳務頁與結算資料作估算；記錄幣別、平台費、稅、匯率、退款與假設；不作收益承諾。 |
| 範圍擴張到其他媒體、平台自動化或資料庫 | 嚴格維持靜態貼圖及三項工具範圍；任何新增商品類型、直接上傳、schema 或資料庫工作均需另立範圍與核准。 |

## 9. 依賴與待確認事項

- CEO 核准的使用者流程、工具使用者、部署環境、資料保存位置及正式素材是否允許進入工具。
- 生成服務是本機模型、已核准免費服務或人工輸入；其授權、資料使用條款、費用與離線需求。
- 第一版是否只產生空白／透明底候選圖，或也提供裁切、去背與調整工具；預設不得以破壞性方式自動修改。
- LINE Creators Market 實際帳號、目標地區及其個別通知／上傳介面要求；本藍圖不使用帳號或自動上傳。
- 是否需要資料庫。初版可先採本機版本化檔案與 manifest；此為規劃假設，不代表已核准架構。若實作前確認需要 schema／migration，必須先另行核准、規劃備份與遷移驗收。
- 人力、預算、時程與支援方式尚未確認，因此里程碑按交付順序排列，不構成日期或費用承諾。
