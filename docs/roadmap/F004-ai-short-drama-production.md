# F004 AI 短劇製作工作流與工具開發藍圖

- 藍圖編號：F004；版本：1.0；建立日：2026-11-17
- 負責部門：影音；開發支援，法律／品管／財務協作
- 狀態：規劃文件；產品功能、生成服務、自動上架尚未實作或核實
- 配套：[工作流](../governance/ai-short-drama-production-workflow.md)、[劇本](../standards/ai-short-drama-script-standard.md)、[角色](../standards/ai-short-drama-character-standard.md)、[場景道具](../standards/ai-short-drama-scene-standard.md)、[分鏡](../standards/ai-short-drama-storyboard-standard.md)、[QA](../standards/ai-short-drama-qa-checklist.md)、[法律](../standards/ai-short-drama-legal-checklist.md)、[財務](../standards/ai-short-drama-finance-checklist.md)

## 1. 目標
規劃可追溯的 AI 輔助短劇工作能力，涵蓋企劃、故事聖經、劇本、角色／場景／道具、分鏡、畫面與影片候選、配音音效、剪輯字幕、QA／法律／財務、上架與追蹤。每季、集、場、鏡、素材都有 ID、版本、來源、核准和證據。工具協助整理與追蹤，不能自動決定創意、權利、付款、法規或發布。

## 2. 範圍與排除
納入規劃：季集管理、單集鉤子、劇本版本／修訂、角色情境造型、場景光線與道具連續性、分鏡依賴、單鏡重做、生成輸出 manifest／hash、字幕剪輯交接、平台規格設定檔、獨立簽核與發布後指標。
排除：未核准付費／雲端 API／資料傳輸；自動投稿上架、簽約付款、稅務申報或對外聯絡；AI 自動法律或發布決定；未授權真人仿聲／換臉、爬取、批量生成；F002-A 不支援的多媒體脫敏保證；未核准新增依賴、改任務中心 schema、migration 或正式資料庫操作。

## 3. 部門責任
CEO 核准題材、預算、服務、敏感資料類別、重大變更、例外和發布。影音企劃撰寫季集與劇本；美術／影片／後期依核准素材產生候選並剪輯；開發在另行核准後建工具；QA 獨立測試；法律查來源、權利、法規和標識；財務覆核成本、收益、付款、退款與稅務；秘書／規劃助手彙整待決事項供一次會議，CEO 最終決定。
AI 候選：企劃 ChatGPT Plus、研究 Perplexity、開發 Codex、美術免費圖像 AI、影片免費影片 AI、後期 CapCut／剪映、QA Grok 或免費 AI、法律 Perplexity 初篩＋本機 AI、財務 AI 待指派、秘書 Claude。候選不代表正式指派或已整合；遵守[AI 訂閱政策](../policies/ai-subscription-policy.md)。

## 4. 原則
所有內容採唯一 ID、版本、狀態、責任人和來源；核准版不可被重做覆蓋。修改劇本可找出下游角色／場景／鏡頭／配音／字幕，單鏡重做建立新 run 並重新覆核依賴。各部門簽核分開。生成留工具／模型版、提示詞版、run、時間、輸入資產、輸出 hash、人工改動與 AI 標識。敏感資料先在本機最小化；F002-A 只處理任務文字，不是多媒體檢查器。每次上架前重查平台和監管當期設定檔。AI 不可核准支出、權利或發布。

## 5. 里程碑與驗收
| 里程碑 | 交付與完成條件 | 前置 |
|---|---|---|
| M0 需求／風險 | 使用者流程、首作題材、季集模式、素材來源、資料分類、存放、平台、預算、服務、合規矩陣及 CEO 決策清單；CEO、法律、QA、財務核准各自方法。 | 本文件不授權實作，須另核准。 |
| M1 人工流程試行 | 用空白範本和合成／已授權素材走完一集全流程；ID 串接、鉤子與單鏡修改可追蹤，沒有上傳或付費。 | M0。 |
| M2 製作管理最小工具 | 季／集／劇本／資產／分鏡版本、變更單、manifest、審核狀態與匯出；合成資料測試、版本差異、權限及故障驗收通過。 | M1；資料模型／schema 另案核准。 |
| M3 單一生成服務試片 | 僅整合另核准的免費／付費圖片、影片或音訊服務之一；含費用、條款、資料流、標識、失敗與單鏡重做測試。 | 服務、資料類別、雲端及費用核准。 |
| M4 QA／平台預檢 | 剪輯字幕交接、紅果當期平台設定檔、許可／備案／AI 聲明、法律／QA／財務證據包。 | M3、各責任部門核准。 |
| M5 發布追蹤試行 | CEO 核准後人工上架；回執、版本、播放／互動／收益來源日期與結案回顧可追溯。 | M4、適用主管機關與平台程序完成。 |

時程、預算、架構及 schema 尚未核准；每一實作切片、服務串接、資料庫變更、付費和正式上傳皆須另行核准。

## 6. 驗收總則
分季集 ID、單集鉤子和承接可查；劇本修改能追到依賴；角色／場景／道具／光線連續；單鏡重做保留舊版並重驗；權利來源、生成版本、AI 標識完整；QA／法律／財務分別簽核；紅果當期規則有官方頁面、日期與核對人；發布有 CEO 明確核准。未核准敏感資料不得上雲。

## 7. 風險與來源
待 CEO 決定首作題材、地域、平台、集數、素材存放、AI 正式指派、服務、預算、真人角色與權利證據責任人。基準來源：[國家廣電總局令第16號《微短劇發展管理辦法》](https://www.nrta.gov.cn/art/2026/7/31/art_113_73785.html)、[《人工智能生成合成內容標識辦法》](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)及配套標準、紅果創作者中心當期官方規則。紅果[官方公告媒體轉載](https://xinwen.bjd.com.cn/content/s69d33570e4b0687a28939a34.html)及[虛擬形象確權資訊](https://finance.sina.com.cn/china/gncj/2026-11-11/doc-iniyitry5296275.shtml)僅為查證線索；發布前以官方原文為準。每半年或重大改版覆核。
